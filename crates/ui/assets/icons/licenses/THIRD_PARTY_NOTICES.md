# Bundled icon notices

Most control icons are Solar Icons (Linear) by 480 Design, fetched with
`@solar-icons/cli` / `@solar-icons/static` 2.3.2. A few glyphs come from other
open icon sets where Solar has no equivalent. Their strokes are set to 1.5 px
so they sit with the Solar Linear weight.

- `webhook.svg`, `package-search.svg`, `git-pull-request.svg`: Lucide
  (`lucide-static` 1.52.0), ISC License. Full text in `LICENSE.lucide`.
- `arrow-fork.svg`: Tabler Icons (`@tabler/icons` 3.49.0, outline), MIT License.
  Full text in `LICENSE.tabler`.
- `mcp-mark.svg`: the Model Context Protocol mark from Simple Icons
  (`simple-icons` 16.34.0), CC0 1.0. The mark itself belongs to its owner.
