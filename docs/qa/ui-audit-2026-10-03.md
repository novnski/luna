# UI audit — 2026-10-03

Scope: `crates/ui` (settings pages and nav, Shell modals, chat transcript error and recovery states, composer, model
picker, right-pane surfaces, file editor, browser previews, UI stream consumers). Backend was reviewed and fixed
separately. Detailed working notes: `/tmp/luna-2026-10-03-ui-audit-handoff.md`.

## Findings fixed

| ID | Area | Defect | Fix |
|---|---|---|---|
| F7 | Keyboard (systemic) | GPUI turns Enter/Space on a focused `on_click` control into one key-up click, and its recorder runs before element `on_key_down`. Over 60 controls also acted on key-down and fired **twice**: General/Notifications/Appearance switches netted to no change, policy and environment cycles skipped a value, "Analyze theme" could import unreviewed, AskUserQuestion single-select could answer the next question, appshot remove could remove the next one, and Retry/insert/rewind ran twice. | `crate::swallow_activation_key` (stops ancestors only); activation through the single keyboard click. Dead helpers removed. |
| F8 | Menus | Theme menu and sidebar view-options triggers mis-toggled from the keyboard; the font-size dropdown opened then closed. | `ClickEvent::is_keyboard()` toggles on open state; `activate_size_from_keyboard`. |
| F4 | Modals | Shell's capture-phase Escape consumed Escape for task/remove-project/sign-out/sync dialogs without closing them. | Escape takes each dialog's Cancel/Later/Continue path. |
| Q1 | Modals | Confirmation dialogs left focus on the composer behind the scrim. Typed keys went into the draft (natively: `"qa draft"` became `"qa draft "`), Enter could submit, and Tab went behind the overlay. | `Shell::sync_confirmation_focus`: the dialog card takes focus while open; previous focus is restored on close when focus is anywhere in the dialog (`contains_focused`). `trap_confirmation_tab` keeps Tab/Shift+Tab cycling inside the dialog. |
| F9 | Dialog buttons | `popover::btn_ghost/primary/danger` were not focusable or announced. | Return `popover::DialogButton`; its `.id(..)` applies role Button + label; tab stop, layout-neutral focus border. No call-site churn. |
| F11 / L2 | Focus layout | A focus-only `border_2()` (applied during layout) grew auto-sized rows by 4 px. Natively, settings-nav rows below the focused one shifted (445.8 pt changed region). | `theme::focus_ring` (2 px inset shadow, no layout effect) at all sites, including the multi-line nav/stash sites; `settings::widgets::switch_control` for switch wrappers. |
| F12 | Settings actions | Backups, Accounts, Devices, Harnesses, Shortcuts actions and the engine/workspace/files/provider-switch retries were pointer-only. | `crate::AccessibleButton::accessible_button(label, focus)`, applied only while enabled. |
| F13 | Files settings | Toggles had no role or keyboard path; delay chips not radios; missing row divider. | `switch_control`, RadioButton chips, divider. |
| F1, F10 | Error/recovery | Recovery trailer, failed-send retry and file-editor banners were pointer-only text; banners used Title Case. | `trailer_action`, `banner_action`, `editor_comment_action` a11y; sentence case. |
| F2, F3 | Copy | "Open Accounts" and "Settings → Accounts/Agents" named retired pages. | "Open Providers", "Settings → Providers". |
| F5 | Streams | Native-tasks watch ended on any transient subscribe error. | Only `UnknownMethod`/`BadParams` end it; otherwise retry every 2 s. |
| F6 | Import | The real import failure cause was replaced by a generic "stream ended". | The specific error replaces it. |
| Q2 | Browser | Previews on a host without `WatchPreviews` showed "It will appear here automatically" plus an endless "Connecting…". | `subscribe_checked`; on `UnknownMethod`, stop and say discovery is unavailable on that device. |
| Q3 | Recovery | "Retrying in Ns" had no re-render source and could freeze. | One-second transcript tick only while a scheduled retry is ahead. |
| F14, F15 | Nav / fixtures | Appshots shared the Devices icon; `settings/files` and `settings/backups` were not fixture routes. | `FILE_IMAGE` icon; routes added. |
| Q1 follow-up | Modals | The "Don't show this again" checkbox had a tab stop but no visible focus indicator. | Same inset `focus_ring`, with a layout-neutral inset. |
| L10 fixture | QA tooling | `drafts-fixture` turn-recovery created projectless chats, hidden since projects became required, so recovery could not be reached. The process also outlived its last window, with no usable Quit. | Fixture project for both chats; GPUI `QuitMode::LastWindowClosed` after the window close guard, the standard menu bar (Quit/⌘Q through the save guard), and engine shutdown exactly once from the quit hook. |

## Not verified natively

- **Q2 (browser previews on an unsupported host):** source-confirmed and implemented. It needs a host without
  `WatchPreviews`.
- **Other confirmation variants:** Remove project, Delete, Settle, Sign out and the sync notices share Archive's
  code path (`confirmation_card`, the Escape routes and the Tab trap), but only Archive was exercised natively.
- **LC2 (fixture menu Quit / ⌘Q with an unsaved draft):** verified in source only (`Quit` → `prepare_quit` save
  guard → `quit_after_save`). The native close path (LC1) passed.
- **Other F7 controls:** settings switches were exercised natively. The other double-activation sites (wizard
  options, appshot remove, theme import, usage card, rewind/insert) are covered by source review and the UI test
  suite, not by native runs.

## Method notes

- The automation's display-mode Escape is not delivered to the app; Escape was sent as raw or background input.
- No Screen Recording permission was granted. Captures were operator-supplied (`preflight --external-capture`,
  `snap --image`), and JPEG captures need `pixels --threshold 32`.
- The L10 launcher now builds through `scripts/cargo.sh --locked`.
