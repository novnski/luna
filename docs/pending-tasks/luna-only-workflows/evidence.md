## Findings that must not become duplicate feature work

- Interactive HTML/MCP Apps/search now have an explicit [IC plan](../interactive-chat-surfaces/README.md). Their renderer, storage and app bridge remain that plan's responsibility.
- The 10 October LUNA SDK conversation reporting automation/editor state, Board counts/deletion and chat-image handoff is followed by [delivered fixes](../../design/board-automation-ticket-fixes/verification.md), including the five existing ticket IDs. SW-12 verifies these current paths; it does not relabel them missing.
- Settled-ticket deletion, own-chat structured attachment reuse, helper chats, worktrees, Git actions, native questions, history and schedules already exist. Their documented limits and fresh E2E readback determine migration work.
- Older timeline defects are historical leads. Current [timeline suite](../../../crates/engine/tests/timeline_order_e2e.rs) includes chronological/part-identity regressions. SW-05 adds only demonstrably uncovered cases.
- Claude restricted-mode configuration loss remains visible in [permissions](../../../crates/engine/src/permissions.rs) and [MCP inventory](../../../crates/engine/src/claude_mcp.rs). A control-only resource inspection is not an active conversation's callable connection.
- Nine retained dictation records and two potentially overlapping transcription records provide limited voice evidence. Direct phone control is already owned by [Control this Mac](../control-this-mac/README.md). Neither justifies silently broadening the core desktop release.
